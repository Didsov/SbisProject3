# Обязательные вложения кампании ЭТрН

Перед реальной отправкой поместите в этот каталог два исходных PDF:

1. `Чек-лист подключения бизнеса к электронным транспортным накладным (ЭТрН).pdf`
2. `КП Saby TMS Электронные перевозочные документы ЭТрН (основное).pdf`

Команда `send` проверяет оба файла до обращения к SMTP и завершается без
отправки, если хотя бы один документ отсутствует.
